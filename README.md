# Disaster Resource Management System


## Prerequisites

- Git
- Python 3.14
- uv (Setup below)

## SETUP
(uv is python package and project manager)

1. Clone the repository
```bash
git clone https://www.github.com/devanksinghchaudhary/school_project.git
cd school_project
```

2. Install uv

Windows (PowerShell)
```bash
pip install uv
```

3. Install project dependencies
```bash
uv sync
```

4. Run the project
```bash
uv run main.py
```
